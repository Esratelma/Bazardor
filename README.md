# 🛒 বাজার দর | BazarDor

**বাজার দর (BazarDor)** is a web application designed to help users explore products, check prices, and make informed shopping decisions through a simple and user-friendly interface. The project focuses on making everyday shopping more convenient with an accessible, Bangla-friendly experience.

---

## Project Overview

BazarDor aims to simplify the shopping experience by providing an organized platform where users can browse products and access relevant product information. Its interface is designed to make everyday shopping easier and more intuitive.

## 🛠️ Technologies Used

- **HTML5** — Semantic page structure
- **CSS3** — Styling, responsive layouts, and visual design
- **JavaScript (ES6+)** — Interactive functionality and dynamic user experiences
- **Next.js** — React-based framework for building the web application
- **API Integration** — Retrieving and managing product-related data
- **Git & GitHub** — Version control and project collaboration

## ✨ Key Features

### 1. 🛍️ Product Browsing
Explore products through an organized interface that makes product discovery easier.

### 2. 💰 Product Price Information
View available product prices to support informed shopping decisions.

### 3. 🔎 Product Search
Find products quickly using search functionality, reducing the time required to locate specific items.

### 4. 📱 Responsive User Interface
Access the application through different screen sizes, including desktop, tablet, and mobile devices.

### 5. 🇧🇩 Bangla-Friendly Experience
Enjoy a user interface designed with Bangla-speaking users in mind, making the application more accessible to local shoppers.
